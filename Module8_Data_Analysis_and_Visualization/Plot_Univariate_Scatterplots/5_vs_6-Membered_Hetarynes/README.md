### Directory Overview:
This directory contains the '5_vs_6_Univariate_Scatter_Plots.ipynb' Jupyter Notebook. 
Use this notebook to generate univariate scatterplots of quantitative molecular descriptors (extracted from DFT calculations) vs. Calculated Dehydrogenation Energy. 

### Motivation:
Is there a clear descriptor that correlates highly with DFT-calculated dehydration energies?
